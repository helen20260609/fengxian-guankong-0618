## 1 巡查任务管理

### 1.1 功能概述

巡查任务管理是风险巡查管理模块的主入口，承担"任务台账 + 状态流转 + 批量导入 + 回头看入口"四大职能。

- 支持按 6 个页签浏览：全部 / 日常巡查 / 专项巡查 / 临时巡查 / 隐患复查 / 回头看（2026）。
- 顶部提供 6 项关键指标（待接收、进行中、已逾期、待销号、高紧急、完成率）。
- 提供多维度筛选（任务名称、镇/街道、村/居委、巡查人员、紧急程度、房屋类型、结构形式、状态、开始日期区间）。
- 行内操作按任务状态差异化呈现：草稿（编辑/删除）、任务回退（修改/删除）、待接收（接收任务/查看）、进行中（完成任务/调整/查看）、已完成/已终止（仅查看）。
- 回头看页签支持批量导入（排查详情 60 列、隐患整治 26 列两种 Excel 模板），并按"镇|村"聚合已提交记录生成巡查任务。
- 查看按钮按任务类型分流：回头看任务进入排查详情页；其他任务进入巡查任务详情页。

### 1.6 业务规则

1. 任务编号规则：新增页生成格式 `FX-RW-年份-月份日期-4位随机数`；新增任务弹窗自动生成格式 `FX-RW-年份-序号`。
2. 回头看任务编号规则：编号格式 `FX-RW-2026-HLT-哈希值`，任务标识格式 `R2026-镇名-村名`。
3. 逾期判定：任务状态为"进行中"且当前日期晚于截止日期，视为已逾期；逾期完成单独打标。
4. 待销号判定：发现隐患数大于已整改隐患数。
5. 高紧急判定：紧急程度为"高"。
6. 完成率：已完成任务数 ÷ 任务总数 × 100（取整）。
7. 隐患判定（回头看）：排查结论中出现"隐患、危险、C 级、D 级、需要整改、存在"等关键词。
8. 排序规则：按任务状态排序权重升序；同状态按创建时间倒序。
9. 分页规则：每页 10 条；链接中携带任务标识时自动切换到对应页签、定位到第 1 页并将目标行置顶高亮。
10. 完成同步：完成任务后，结果将双向同步至房屋档案模块。
11. 批量导入：解析 xlsx 文件，支持排查详情 60 列、隐患整治 26 列两种模板；导入成功后记录状态为"已提交"、来源标记为"PC 端导入"、并打上"PC 已补充"标记。

## 2 新增巡查任务

### 2.1 功能概述

新增巡查任务采用三步向导（基本信息 → 选择范围 → 确认发布），用于创建一次性巡查任务。支持三种模式：

- **新增模式**：默认入口，从巡查任务管理列表点击"新增任务"进入。
- **编辑模式**：链接中携带"编辑模式 + 任务标识"，加载已有草稿进行修改。
- **退回修改模式**：链接中携带"退回修改模式 + 任务标识"，展示退回原因与历史，提交后重新进入审核。

| 任务类型 | 下拉选择框 | 是 | 日常巡查 / 专项巡查 / 临时巡查 / 隐患复查 |
| 紧急程度 | 下拉选择框 | 是 | 高 / 中 / 低 |
| 指派单位 | 组织树弹窗 | 是 | 选择本部门时视为本部门自派；选择其他单位时视为外部指派 |
| 指派人员 | 组织树弹窗 | 否 | 外部单位时禁用，提示"由指派单位管理员分配" |

## 10 巡查任务分析

### 10.1 功能概述

巡查任务分析页是 GIS 地图可视化 + 统计分析驾驶舱，采用三栏布局（区域列表 | 地图 + 趋势 | 分布 + 排名），基于地图组件与图表组件，数据来源为浏览器本地任务库。

### 10.2 输入字段

本页无表单输入；筛选通过交互控件实现：

| 控件名称 | 说明 |
|---|---|
| 图层开关 | 任务点位 / 风险点位 / 整改点位 三类点位的显隐开关 |
| 时间轴 | 滑块 0-29 对应 2025-06-01 起 30 天 |
| 时间粒度 | 日 / 周 / 月（当前版本仅样式切换，未联动数据） |

### 10.3 输出字段

**左栏区域列表**：12 个街镇，每项显示完成率、隐患数、整改率。

**中栏地图**：任务/风险/整改三类点位，点击弹窗显示类型、状态/等级、发现时间、责任人、所属区域、坐标。

**中栏趋势图**：近 7 天巡查发现趋势（折线 + 面积）。

**右栏饼图**：风险等级分布（第三类 12 / 第二类 34 / 第一类 20）。

**右栏排名**：镇/街道巡查完成排名（第 1 名红色徽章 / 第 2 名黄色徽章 / 第 3 名蓝色徽章 + 进度条）。

**弹窗统计**：完成率、隐患数、整改率 + 区域风险等级构成柱状图。

### 10.4 查询条件

无表单查询条件；通过图层开关、时间轴、区域点击进行数据过滤。

### 10.5 数据生命周期

| 阶段 | 触发 | 状态 | 数据落点 |
|---|---|---|---|
| 加载 | 页面初始化 | 读取浏览器本地任务库 | 无数据时回退到演示数据 |
| 区域下钻 | 点击区域列表 | 打开区域统计弹窗 | - |
| 点位点击 | 点击地图点位 | 打开点位信息弹窗 | - |

### 10.6 业务规则

1. 完成率：已完成任务数 ÷ 任务总数 × 100（取整）。
2. 整改率：已整改数 ÷ 整改总数 × 100（取整）。
3. 任务完成判定：任务状态为"已完成"，或状态文本含"完成"，或状态样式为成功。
4. 点位类型判定：类型为"风险"或类型文本含"风险/专项" → 风险点位；发现隐患数大于已整改隐患数 → 整改点位；其他 → 任务点位。
5. 风险等级映射：根据风险等级/紧急程度文本自动识别为高/中/低。
