## 1 巡查任务管理（patrol-task-management.html）

### 1.1 功能概述

巡查任务管理是风险巡查管理模块的主入口，承担"任务台账 + 状态流转 + 批量导入 + 回头看入口"四大职能。

- 支持按 6 个 tab 浏览：全部 / 日常巡查 / 专项巡查 / 临时巡查 / 隐患复查 / 回头看（2026）。
- 顶部提供 6 项 KPI（待接收、进行中、已逾期、待销号、高紧急、完成率）。
- 提供多维度筛选（任务名称、镇/街道、村/居委、巡查人员、紧急程度、房屋类型、结构形式、状态、开始日期区间）。
- 行内操作按任务状态差异化呈现：草稿（编辑/删除）、任务回退（修改/删除）、待接收（接收任务/查看）、进行中（完成任务/调整/查看）、已完成/已终止（仅查看）。
- 回头看 tab 支持批量导入（排查详情 60 列、隐患整治 26 列两种模板），并按"镇|村"聚合已提交记录生成巡查任务。
- 查看按钮按任务类型分流：回头看任务跳 review-2026-detail.html；其他任务跳 rural-risk-task-detail.html。

### 1.5 数据生命周期

| 阶段 | 触发动作 | 状态变化 | 存储 |
|---|---|---|---|
| 创建 | 新增任务弹窗保存 | 无 → draft | localStorage patrolTasks |
| 发布 | 在新增页确认发布 | draft → issued | patrolTasks |
| 接收 | 行内"接收任务" | issued → processing | patrolTasks |
| 完成 | 行内"完成任务" | processing → completed | patrolTasks + syncTaskToHouseRecords |

### 1.6 业务规则

1. 任务编号规则：`FX-RW-YYYY-序号`（新增页生成）/ `FX-RW-YYYY-MMDD-XXXX`（新增任务弹窗自动生成）。
2. 回头看任务编号规则：`FX-RW-2026-HLT-{hash}`，任务 id 格式 `R2026-{镇}-{村}`。
3. 逾期判定：`status === 'processing' && today > endDate` 视为已逾期；逾期完成单独打标。
4. 待销号判定：`hiddenCount > hiddenFixed`。
5. 高紧急判定：`urgency === 'high'` 或 `urgencyLabel === '高'`。
6. 完成率：`completed / total * 100`（取整）。
7. 隐患判定（回头看）：`answers.conclusion` 或 `answers.result` 匹配正则 `/隐患|危险|C级|D级|需要整改|存在/`。
8. 排序规则：按 statusOrder 权重升序，同状态按创建时间倒序。
9. 分页规则：每页 10 条；URL 携带 taskId 时强制切到对应 tab 第 1 页并置顶高亮。
10. 完成同步：完成任务后调用 `syncTaskToHouseRecords` 双向同步至房屋档案。
11. 批量导入：xlsx 解析，支持排查详情 60 列、隐患整治 26 列；导入后 `status='submitted'`、`source='pc-import'`、`editedByPC=true`。

## 2 新增巡查任务（rural-risk-task-add.html）

### 2.1 功能概述

新增巡查任务采用三步向导（基本信息 → 选择范围 → 确认发布），用于创建一次性巡查任务。支持三种模式：

- 新增模式：默认入口，从巡查任务管理列表点击"新增任务"进入。
- 编辑模式：URL `mode=edit&id=`，加载已有草稿进行修改。
- 退回修改模式：URL `mode=returned&id=`，展示退回原因与历史，提交后重新进入审核。

### 2.2 输入字段

| 分组 | 字段 | 控件 | 必填 | 说明 |
|---|---|---|---|---|
| 基本信息 | 任务名称 taskName | 单行文本框 | 是 | - |
| 基本信息 | 任务类型 taskType | 下拉选择框 | 是 | routine / special / temporary / review |
| 基本信息 | 紧急程度 urgencyLevel | 下拉选择框 | 是 | high / medium / low |
| 基本信息 | 指派单位 assignUnit | 组织树弹窗（unitTrigger） | 是 | dept1~dept17 映射 self（本部门）/ other（外部指派） |
| 基本信息 | 指派人员 personTrigger | 组织树弹窗 | 否 | 外部单位时禁用并提示"由指派单位管理员分配" |
| 基本信息 | 任务时限 taskStartDate / taskEndDate | 日期区间选择 | 是 | 默认今天 ~ 今天+7 天 |
| 基本信息 | 任务要求 taskDesc | 多行文本框 | 否 | 重点关注事项 |
| 选择范围 | 街镇/村 selectedTownIds / selectedVillageIds | 卡片多选 + 复选框 | 是 | 街镇卡片下钻村列表，支持"全镇" |
| 选择范围 | 房屋类别 selectedCategoryIds | 卡片多选 | 否 | key 重点 / construct 在建 / routine 常规 |
| 选择范围 | 类别筛选 catFilterAge / catFilterPatrol / catFilterKeyword | 下拉 + 单行文本框 | 否 | 房龄、最近巡查、关键词 |
| 选择范围 | 风险清单 selectedRiskListIds | 复选框（表格） | 否 | 5 条静态清单 |
| 选择范围 | 自定义检查项 customPatrolItems | 动态行表格 | 否 | 主项/分项/分项内容/风险辨识/可能导致事故/风险等级 |
| 确认发布 | 全部字段 | 只读回显 | - | 3 步确认 |

### 2.3 输出字段

| 字段 | 说明 |
|---|---|
| 任务 id | 新增时自动生成 |
| 任务编号 no | FX-RW-YYYY-MMDD-XXXX |
| 状态 status | draft（新增）/ rejected（退回重新提交） |
| 创建时间 createTime | ISO 字符串 |
| 已选范围 selectedProjects | 房屋/村列表 |
| 检查项 checkItems | 自定义检查项数组 |
| 风险清单 riskLists | 已选风险清单 id 数组 |

### 2.4 查询条件

本页为创建页，不提供查询条件；仅类别明细面板支持房龄、最近巡查、关键词过滤。

### 2.5 数据生命周期

| 阶段 | 触发 | 状态 | 存储 |
|---|---|---|---|
| 暂存 | 点击"暂存草稿" | draft | localStorage patrolTasks |
| 发布 | 第 3 步确认发布 | issued | patrolTasks |
| 编辑 | 列表"编辑"进入 | draft | patrolTasks（按 id 替换） |
| 退回重提 | 列表"修改"进入 | rejected | patrolTasks（按 id 替换） |
| 提交后跳转 | 成功 alert 后 | - | 跳 patrol-task-management.html |

### 2.6 业务规则

1. 任务编号生成规则：`FX-RW-{year}-{month}{day}-{4位随机}`。
2. 新增模式初始状态为 draft；退回重新提交后状态保持 rejected。
3. 指派单位选择 dept1 时为本部门 self，可继续选择指派人员；选择其他单位时为外部指派，人员选择禁用。
4. 房屋类别联动：仅当已选街镇/村后，类别卡片才显示对应房屋。
5. 风险等级枚举：第一类（蓝）、第二类（黄）、第三类（红）。
6. 第 3 步未选择房屋类别时显示黄色警示"未选择房屋类别，任务发布后房屋数将为 0"。
