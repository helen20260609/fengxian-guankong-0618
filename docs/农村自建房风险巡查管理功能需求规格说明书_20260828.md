# 1 风险巡查任务管理

## 1.1 功能概述

风险巡查任务管理页（patrol-task-management.html）是农村自建房风险巡查业务的统一入口与工作台，承担巡查任务（日常巡查、专项巡查、临时巡查、隐患复查）的全生命周期查询、浏览与分发管理，同时集成2026年农村自建房安全专项整治"回头看"排查记录的聚合展示与批量导入能力。页面以 Tab 分类组织任务清单，支持多维度组合筛选，为区、镇两级管理人员提供任务总览、进度跟踪与任务操作（查看、调整）入口。

## 1.2 输入字段

| 字段名称 | 控件类型 | 是否必填 | 详细业务说明 |
| --- | --- | --- | --- |

| 镇/街道 | 下拉选择框 | 否 | 枚举：南桥镇、奉城镇、庄行镇、金汇镇、青村镇、柘林镇、四团镇、海湾镇、西渡街道、奉浦街道、海湾旅游区、头桥街道、金海街道；默认"全部" |
| 村居委 | 可搜索下拉选择框 | 否 | 依据已选镇/街道联动加载下辖村居委，支持关键字搜索；默认"全部" |
| 巡查人员 | 单行文本框 | 否 | 模糊匹配巡查人员姓名 |
| 紧急程度 | 下拉选择框 | 否 | 枚举：高、中、低；默认"全部" |

## 1.4 查询条件

1. 全部筛选条件支持组合查询，点击"搜索"按钮或筛选控件变更后触发；点击"重置"清空全部筛选条件并恢复默认列表。
2. 镇/街道与村居委为级联关系：选择镇/街道后村居委选项同步刷新；切换镇/街道自动清空已选村居委。
3. 日期范围采用闭区间匹配，命中任务周期与所选区间存在交集的任务。
4. Tab 切换时保留当前筛选条件，仅追加任务类型过滤。
5. 2026回头看 Tab 的筛选条件仅任务名称、镇/街道、村居委、排查人员生效，其余条件不作用于该数据源。

## 1.5 数据生命周期

| 数据状态 | 状态含义 | 进入条件 | 离开条件 | 前端表现 |
| --- | --- | --- | --- | --- |
| 草稿 | 任务已创建暂存未下发 | 新增任务页点击"暂存草稿" | 提交发布或删除 | 灰色标签，仅创建人可见操作入口 |
| 待接收 | 任务已下发，接收单位未接收 | 创建人提交发布 | 接收人接收或退回 | 蓝色标签 |
| 进行中 | 任务已被接收并执行巡查 | 接收人点击"接收并分配人员" | 全部房屋巡查完成、任务回退或终止 | 青色标签，显示进度条 |
| 已完成 | 全部巡查对象完成排查 | 进度达到100%自动流转或人工确认完成 | 不可逆向流转 | 绿色标签，显示完成时间 |
| 任务回退 | 任务被接收单位退回创建人 | 接收人点击"退回任务" | 创建人修改后重新提交 | 红色标签，新增页展示退回横幅 |
| 已终止 | 任务被中途终止不再执行 | 任务调整页执行"任务终止" | 不可逆向流转 | 灰色标签，列表仅可查看 |
| 已逾期 | 超过截至日期未完成 | 系统按当前日期与截至日期比对自动标记 | 任务完成或终止 | 红色"已逾期"标记列 |

## 1.6 业务规则

1. Tab 分为：全部、日常巡查、专项巡查、临时巡查、隐患复查、回头看（2026），共 6 类，各 Tab 展示对应任务类型数量角标。
2. 任务列表默认按创建时间倒序排列；逾期任务在"标记"列强制标注，不受状态筛选影响。
3. "回头看"Tab 数据来源于2026年排查记录，按"镇/街道+村居委"聚合成任务卡片（任务编号规则：R2026-镇-村），发现隐患数>0 的聚合任务紧急程度标记为"高"，否则为"中"，状态固定为"已完成"。
4. 排查户数列以蓝色链接呈现，点击后下钻至该村全部排查记录列表，不触发行点击跳转。
5. 批量导入支持"排查详情导入"与"隐患整治导入"两个子 Tab，导入前须先下载标准模板；导入预览确认后写入，数据同步至 H5 端与 PC 端详情页。
6. 隐患整改情况统计口径：隐患状态为"待审核"或"待处置"均计为未整改。

## 1.7 交互逻辑

1. 点击任务行（非操作链接区域）跳转至 rural-risk-task-detail.html 并携带任务编号参数。
2. 点击"调整"跳转至 rural-risk-task-adjust.html；点击"查看"跳转详情页只读模式。
3. 点击"新增任务"按钮跳转 rural-risk-task-add.html。
4. 2026回头看 Tab 点击"批量导入"打开导入弹窗：弹窗内含 Tab 切换、模板下载链接、文件选择、导入预览列表、"确认导入/取消"按钮；未选择文件时"确认导入"置灰。
5. 导入弹窗点击遮罩层或"取消"关闭，不保留已选文件。
6. Tab 角标实时反映当前筛选结果集各类型数量。

# 2 新增风险巡查任务

## 2.1 功能概述

新增风险巡查任务页（rural-risk-task-add.html）采用"基本信息→选择范围→确认发布"三步分步向导，支撑日常巡查、专项巡查、临时巡查、隐患复查四类巡查任务的创建、范围圈定（按镇/街道、按房屋类别、按风险清单）、自定义检查项维护与任务发布/暂存。被退回任务重新编辑时，页面顶部展示退回原因横幅与历史退回记录，实现任务回退闭环。

## 2.2 输入字段

**第1步 基本信息：**

| 字段名称 | 控件类型 | 是否必填 | 详细业务说明 |
| --- | --- | --- | --- |
| 任务名称 | 单行文本框 | 是 | 不超过50字，同一创建人下不可重名 |
| 任务类型 | 下拉选择框 | 是 | 枚举：日常巡查、专项巡查、临时巡查、隐患复查 |
| 紧急程度 | 单选按钮组 | 是 | 枚举：高（红）、中（橙）、低（蓝） |
| 指派单位 | 组织树弹窗 | 是 | 点击触发组织树弹窗选择城建中心/镇级单位，单选 |
| 指派人员 | 组织树弹窗 | 否 | 须先选择指派单位后激活；不选时由接收单位管理员自主分配，输入框下方展示提示文案"任务指派其他城建中心时，由该中心管理员自主分配具体巡查人员" |
| 任务时限 | 日期区间选择 | 是 | 开始日期至截至日期，截至日期不得早于开始日期 |
| 任务要求 | 多行文本框 | 否 | 巡查要求、重点关注事项说明 |

**第2步 选择范围（按任务类型切换布局）：**

| 字段名称 | 控件类型 | 是否必填 | 详细业务说明 |
| --- | --- | --- | --- |
| 巡查镇/街道 | 卡片多选 | 专项/临时必填 | 镇/街道卡片网格多选，支持全选、重置，已选以标签条展示 |
| 房屋类别 | 卡片多选 | 日常必填 | 重点巡查类、在建施工类、常规巡查类三选一或多选，卡片展示各类别数量 |
| 类别明细筛选-房龄 | 下拉选择框 | 否 | 枚举：5年以下、5-20年、20年以上 |
| 类别明细筛选-巡查日期 | 下拉选择框 | 否 | 枚举：近7日已巡查、近30日已巡查、超30日未巡查 |
| 类别明细筛选-关键词 | 单行文本框 | 否 | 匹配房屋名称/地址 |
| 风险清单 | 复选框列表 | 专项/临时必填 | 展示清单名称、版本号、生成时间、条目数，已选以标签条展示 |
| 自定义检查项 | 动态表格录入 | 否 | 列：主项、分项、分项内容、风险辨识、可能导致事故、风险等级（下拉：重大/一般/轻微）；支持添加行、删除行 |

## 2.3 输出字段

**第2步 房屋类别明细表：** 勾选框、序号、房屋名称、所属街镇、房屋性质、房龄、拆违年份、最近巡查日期。

**第3步 确认发布（只读回显）：** 任务名称、任务类型、紧急程度、指派单位、指派人员、任务时限、巡查范围汇总（镇/街道数、房屋户数、清单名称及版本）、自定义检查项条数、任务要求。

## 2.4 查询条件

本页面为录入页，仅第2步类别明细面板含局部筛选：房龄、巡查日期、关键词，实时过滤明细表格；筛选仅作用于当前类别明细展示，不影响已选数据。

## 2.5 数据生命周期

| 数据状态 | 状态含义 | 进入条件 | 离开条件 | 前端表现 |
| --- | --- | --- | --- | --- |
| 编辑中 | 向导填写过程 | 打开页面 | 暂存或发布 | 步骤条高亮当前步 |
| 草稿 | 暂存未发布 | 点击"暂存草稿" | 再次编辑发布或删除 | 列表灰标签"草稿" |
| 待接收 | 已发布待接收 | 点击"确认发布"且校验通过 | 接收或退回 | 列表蓝标签"待接收" |
| 任务回退 | 被退回待修改 | 接收方退回 | 重新提交 | 顶部红色退回横幅+可展开历史退回记录 |

## 2.6 业务规则

1. 任务编号自动生成，规则：FX-RW-年份-类型缩写-四位流水号，发布后不可修改。
2. 步骤校验：第1步全部必填项通过后方可进入第2步；第2步须至少圈定一个巡查对象（镇/街道或房屋或清单）方可进入第3步。
3. 指派人员选择范围受指派单位约束，切换指派单位时自动清空已选指派人员。
4. 日常巡查按"房屋类别"圈定；专项/临时巡查按"镇/街道+风险清单"圈定；隐患复查自动带入待复查隐患关联房屋，无需手工圈定。
5. 自定义检查项的风险等级决定该检查项在 H5 端的标色：重大（红）、一般（橙）、轻微（蓝）。
6. 退回任务重新提交后，任务状态由"任务回退"流转为"待接收"，退回次数累计+1并写入流转记录。

## 2.7 交互逻辑

1. 步骤条点击仅允许回退至已完成步骤，不允许跳步前进。
2. "上一步/下一步"按钮位于页面底部操作区；第3步显示"确认发布""暂存草稿""上一步"。
3. 镇/街道卡片点击切换选中态（蓝色描边+勾选角标），"全选/重置"批量操作。
4. 已选镇/街道、已选清单、已选房屋均以标签条呈现，标签可单个移除。
5. 退回横幅默认展示最新一条退回记录（退回人、时间、原因），"历史退回记录"折叠面板点击展开全部记录。
6. 确认发布弹出二次确认框："确认发布该巡查任务？发布后将下发至【指派单位】。"

## 2.8 异常提示

# 5 巡查配置管理

## 5.1 功能概述

巡查配置管理页（patrol-task-config.html）用于维护农村自建房周期性/触发式巡查任务的自动生成规则。管理员可按风险等级、镇/街道、房屋类型配置生成周期与任务期限，系统按规则定时或触发式自动生成巡查任务；页面同时提供配置启停开关与近7日配置执行日志，实现巡查任务的自动化编排与运行监控。

3. 查询结果按创建时间倒序排列。

| 数据状态 | 状态含义 | 进入条件 | 离开条件 | 前端表现 |
| --- | --- | --- | --- | --- |

| 已暂停 | 配置停用不生成任务 | 关闭开关 | 重新启用或删除 | 开关关闭（灰），下次生成显示"—" |

## 5.6 业务规则

1. 配置到点自动生成巡查任务，任务继承配置中的任务类型、风险等级（映射紧急程度：第三类→高、第二类→中、第一类→低）、镇/街道、巡查人员。
2. 生成任务的开始日期为生成当日，截至日期=生成日期+任务期限天数。
3. 触发式配置（如"极端天气预警"）不计算下次生成时间，由外部预警事件驱动生成。
4. 已暂停配置不参与自动生成；恢复启用后按下一计划时点生成，不补生成暂停期间任务。
5. 每次自动生成写入配置执行日志，日志保留近7日记录。
6. 删除配置不影响已生成的历史任务。

## 6.6 业务规则

## 10.6 业务规则

1. 仅排查记录状态为"已提交"且存在安全隐患初判（一般或严重）的房屋可进入本页。
2. "完成安全管控"或"完成工程措施"选"是"时，对应措施复选框至少勾选一项；选"否"时措施组禁用清空。
3. 措施勾选"其他"时必须填写对应说明文本框；取消勾选"其他"时说明文本框隐藏并清空。
4. 三类必填签名（产权人、镇审核人、区管理人）缺任一不得保存；签名日期不得晚于当前日期。
5. 保存后整治信息回写排查记录，任务管理页"发现隐患"列状态联动更新为已整治口径。
6. 已保存记录再次进入默认只读模式，点击"编辑整治信息"切换为可编辑，切换不清空既有数据。

## 10.7 交互逻辑

1. 页面分三块卡片纵向排列：初判回显（只读）→鉴定情况→整治情况（含签名区）。
2. 单选/复选选项为药丸按钮，选中蓝色填充；只读模式下全部输入控件禁用、照片删除按钮隐藏。
3. 照片上传组件支持点击上传与预览，照片项含删除按钮（编辑模式）。
4. 完成管控/工程措施单选切换时，对应措施区与其他说明行联动显隐。
5. 点击"保存整治信息"执行全量校验，首个失败字段滚动定位。
6. 保存成功后 Toast 提示并切换为只读模式；取消返回排查记录详情页。
