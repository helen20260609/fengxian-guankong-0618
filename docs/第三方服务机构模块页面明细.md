## 二、机构与申报审核

| 页面文件 | 页面名称 | 定位与主要功能 |
|----------|----------|----------------|
| `tp-overview.html` | 机构总览看板 | 机构、专家、合同、业绩统计卡片；业务分布、机构类型、资质等级图表；服务区域地图；按条件钻取机构名录并跳转详情。 |
| `tp-warehouse.html` | 机构信息管理 | 正式入库机构名录；分页与筛选；查看、编辑、资质复核、变更历史；批量导入和入库统计；“代录机构申报”复用统一申报页面；在线申请审核统一进入申报审核中心。 |
| `tp-audit.html` | 申报审核中心 | 统一处理机构入库、机构信息变更和专家申请；支持多级审核、核验、通过、驳回、附件查看和审核归档；通过 `applicationId` 直接打开申请；监管端与申请人视图分离。 |
| `tp-audit-progress.html` | 审核进度查询 | 独立入口的参数透传页；默认补充 `portal=1` 并跳转申报审核中心的进度页，不展示监管端审核归档。 |
| `tp-org-stats.html` | 机构信息统计 | 按时间、区域、专业领域、机构类型、信用等级等筛选；统计服务质量、满意度、及时率、通过率、新增机构；生成、保存和分享统计报告。 |
| `tp-org-stats-view.html` | 统计报告只读视图 | 按 `reportId` 读取 `orgReports` 中的报告配置并展示统计结果；仅供查看，不可修改；报告不存在时显示失效提示。 |
| `tp-credit.html` | 机构信用管理 | 信用统计、等级分布和趋势；机构信用台账、五维得分和信用详情；记录良好/不良行为；信用变更记录；规则配置与全量重算；支持机构搜索选择和折叠管理区。 |

## 六、左侧菜单入口与顺序

当前 [index.html](../index.html) 中第三方服务机构菜单共 13 个入口，顺序如下：

1. 机构总览
2. 机构在线申报
3. 专家在线申报
4. 申报审核
5. 机构信息管理
6. 专家库管理
7. 申请专家 / 机构评估
8. 鉴定合同管理
9. 机构业绩管理
10. 机构信用管理
11. 机构信息统计
12. 鉴定机构工作台
13. 专家工作台

菜单按“申报准入 → 机构与专家资源 → 评估申请 → 合同履约 → 业绩信用 → 统计分析 → 工作台”排列。其余页面作为弹窗、详情、只读分享或流程跳转页使用，不单独出现在菜单中。

## 七、核心业务流程

### 1. 机构入库申报

- 机构自主申报：左侧菜单“机构在线申报”进入 `tp-org-apply.html`。
- 监管端代录：机构信息管理点击“代录机构申报”，进入 `tp-org-apply.html?agent=1`。
- 两种入口共用表单、校验、附件和 `submitOrgApplication()`，分别记录“机构自主申报”和“监管端代录”。
- 提交后进入 `tp-audit.html`，审核通过由 `promoteApplicationToOrg()` 正式入库。
- 入库后进入合同、业绩、信用和统计流程。

### 2. 驳回补充与信息变更

- 驳回补充：`tp-org-apply.html?resubmit=申请编号` 回填原申请，附件可重新上传，重新提交后保留审核历史。
- 信息变更：`tp-org-apply.html?change=机构编号` 填写变更字段和原因，进入变更审核，通过后由 `applyOrgChangeRequest()` 更新机构及关联数据。

### 3. 专家申请与任务流转

- 专家自主申请：`tp-expert-apply.html` 提交后进入申报审核中心，通过后由 `promoteApplicationToExpert()` 写入专家库；职称等级随申报数据入库，缺失时由 `inferExpertTitleLevel()` 按职称名称自动推断（教授级/正高/教授/研究员→正高级；高级工程师/副教授/注册类→副高级；助理/技术员→初级；其余→中级）。
- 评估/鉴定申请：`tp-expert-dispatch.html` 创建申请并选择专家或机构，任务同步到对应工作台，完成响应和成果反馈。

### 4. 业绩审核与导出

- 单条录入或批量导入后均为“待审核”。
- 在机构业绩管理中查看、编辑和审核；通过后正式入库，退回时记录原因。
- 查询筛选后导出的范围为当前筛选结果，而不是固定全量数据。

### 5. 初始信用与后续评价

- 新审核入库机构统一初始化为 **75 分、B 级**，自动创建信用档案、初始记录、变更日志和当日快照。
- 无合同、无业绩时重算保持初始信用，履约信用、质量信用和客户评价显示“暂无数据”，不按 0 分处理。
- 有业务数据后按基础信用 25%、履约信用 25%、质量信用 25%、行为信用 15%、客户评价 10% 计算，再叠加启用的规则加减分。
- 等级区间：AAA ≥ 90、AA ≥ 85、A ≥ 80、B ≥ 70、C < 70；规则可配置强制降级。

## 八、常用页面参数

| 参数 | 使用页面 | 用途 |
|------|----------|------|
| `agent=1` | `tp-org-apply.html` | 标识监管端代录，显示代录提示并记录“监管端代录”来源。 |
| `resubmit=申请编号` | `tp-org-apply.html` | 驳回后回填资料并重新提交。 |
| `change=机构编号` | `tp-org-apply.html` | 发起机构信息变更申请。 |
| `portal=1` | `tp-audit.html`、`tp-audit-progress.html` | 进入申请人进度视图，隐藏监管统计、页签和审核归档。 |
| `applicationId=申请编号` | `tp-audit.html` | 直接打开待审核申请或已完结详情。 |
| `orgId=机构编号` | 多个机构业务页面 | 限定当前机构上下文或打开机构详情。 |
| `embed=1` | 信用、业绩等嵌入页面 | 使用嵌入模式样式，适配机构名录弹窗。 |
| `reportId=报告编号` | `tp-org-stats-view.html` | 打开指定统计报告的只读分享视图。 |
| `id=业绩编号&mode=edit` | `tp-performance-detail.html` | 打开指定业绩并进入编辑模式。 |

## 九、共享文件与数据

### 共享文件

| 文件 | 用途 |
|------|------|
| `js/third-party-data.js` | 统一机构、申请、专家、合同、业绩、信用、变更和消息数据及持久化方法；含版本化数据迁移（v7 补专家职称等级、v8 清理同名重复专家）和 `inferExpertTitleLevel()` 职称等级推断。 |
| `js/tp-friendly-tip.js` | 统一友好提示和确认弹窗。 |
| `pages/tp-common.css` | 第三方页面公共主题、卡片、表格、按钮和弹窗样式。 |
| `pages/tp-expert-view.js` | 专家详情页面的数据加载与渲染逻辑。 |
| `pages/tp-performance-modal.html` | 机构业绩管理共用的弹窗结构。 |

### 主要本地存储

| 存储键 | 内容 |
|--------|------|
| `thirdPartyData` | 机构 `orgs`、机构申请 `orgApplications`、专家申请 `expertApplications`、信息变更 `orgChangeRequests`、专家 `experts`（含职称名称 `title`、职称等级 `titleLevel`）、合同 `contracts`、业绩 `performances`、信用 `credit`、信用规则、审核流程和通知消息；当前数据版本 v8，同名专家按姓名去重。 |
| `performanceData` | 业绩录入、导入和编辑的本地版本，与共享数据层合并展示。 |
| `auditListData` | 业绩审核台账及审核结果记录。 |
| `orgReports` | 机构统计报告配置，用于统计报告只读分享。 |

当前版本为纯前端演示，主要使用浏览器 `localStorage` 持久化；清理浏览器数据可能影响已录入内容。
