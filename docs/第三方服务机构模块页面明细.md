# 第三方服务机构模块页面明细

> 导出时间：2026-10-28
> 模块共 25 个页面（pages/tp-*.html）+ 1 个共享数据层（js/third-party-data.js）

## 一、监管端 — 机构管理

| 页面文件 | 页面名称 | 功能说明 |
|----------|----------|----------|
| tp-overview.html | 机构总览看板 | 机构/专家/合同/业绩统计卡片、地图点位分布、图表钻取 |
| tp-warehouse.html | 机构入库管理 | 入库机构名录（分页/筛选）、查看/编辑/审核/变更历史、入库统计 |
| tp-audit.html | 申报审核中心 | 审核机构入库申请与信息变更申请，通过后实时生效（promoteApplicationToOrg） |
| tp-audit-progress.html | 审核进度查询 | 机构侧查询自己申请的审批进度 |
| tp-org-stats.html | 机构信息统计 | 按专业领域/月度等多维度统计分析 |
| tp-credit.html | 机构信用管理 | 信用评分、信用记录维护 |

## 二、监管端 — 合同与业绩

| 页面文件 | 页面名称 | 功能说明 |
|----------|----------|----------|
| tp-contract.html | 鉴定合同管理 | 合同台账、新建/编辑/删除、上传鉴定报告、确认验收（已验收→已完成） |
| tp-performance.html | 机构业绩管理 | 业绩列表（合并数据层+录入数据）、筛选、详情、审核、删除、凭证查看 |
| tp-performance-entry.html | 业绩录入 | 机构单条录入业绩（写 localStorage） |
| tp-performance-batch-entry.html | 业绩批量导入 | 批量录入业绩 |
| tp-performance-detail.html | 业绩详情 | 单条业绩完整信息 + 证明材料 |
| tp-performance-export.html | 业绩证明导出预览 | 打印/导出用视图 |
| tp-performance-modal.html | （弹窗组件） | 业绩弹窗组件（嵌入模式，无独立标题） |

## 共享数据层

**js/third-party-data.js** — 所有 tp 页面共用，localStorage 键 `thirdPartyData`。

管理数据：
- 机构 `orgs`
- 申请 `applications`
- 专家 `experts`
- 合同 `contracts`
- 业绩 `performances`
- 变更历史

提供方法：`getAllOrgs` / `getAllContracts` / `getAllPerformances` / `updateContract` / `deleteContractById` / `updatePerformance` / `promoteApplicationToOrg` / `getOrgChangeHistory` 等持久化方法。
