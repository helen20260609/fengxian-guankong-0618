# 在建工地信息 · 移动端设计稿（文字版）

## 一、设计定位

- **使用场景**：防汛防台应急期间，指挥人员、巡查人员在移动端快速查询在建工地底数、人员转移规模、联系人电话与安置场所，支撑**人员转移撤离决策与现场联络**。
- **功能边界**：**只读查看**，无新增、编辑、删除、导入导出、地图选点功能（数据维护在 PC 端完成）。
- **字段原则**：PC 端台账字段全部保留、不遗漏——工程项目名称、所属街镇、工程地址、施工单位名称、项目级别、项目类别、组织撤离单位名称、总人数、有无应急预案、需转移安置人数、安置场所名称、安置场所地址、联系人、职务、联系方式、填报单位、填报人、填报日期，以及位置坐标（经度、纬度）。
- **移动端增值点**：联系人电话一键拨打；工地地址、安置点地址一键复制；「有无应急预案」以红绿徽标前置，一眼识别风险工地；筛选改为底部抽屉，适配单手操作。

## 二、页面结构总览

```
列表页（默认页）
├── 顶部导航栏：标题「在建工地信息」+ 副标题「防汛防台在建工地台账 · 仅供查询」
├── 搜索区：关键字搜索框 + 筛选按钮（带激活红点）
├── 已选筛选条件 Chips（可单个移除）
└── 工地卡片列表（点击卡片 → 详情页；卡片内「拨打」按钮直拨联系人）

详情页（右滑进入）
├── 顶部导航栏：返回按钮 + 「在建工地详情」
├── 头部卡片：工程名称 + 级别/类别/街镇标签 + 总人数/需转移安置人数
├── 快捷操作区：拨打联系人 / 复制工地地址 / 复制安置点地址
├── 项目基础信息卡片：工程名称、所属街镇、工程地址、施工单位、级别、类别、应急预案、经纬度
├── 撤离安置信息卡片：组织撤离单位、总人数、需转移安置人数、联系人、职务、联系方式
├── 安置场所信息卡片：安置场所名称、安置场所地址
└── 填报信息卡片：填报单位、填报人、填报日期

筛选抽屉（列表页底部弹出）
├── 项目级别：全部 / 市级 / 区级 / 镇级（单选）
├── 所属街镇：全部 / 各街镇（单选，由数据动态生成）
├── 应急预案：全部 / 有 / 无（单选）
├── 填报日期：开始日期 ~ 结束日期
└── 底部操作：重置 / 确定
```

## 三、列表页详细设计

### 3.1 顶部导航栏
- 蓝色渐变底（延续 PC 端主色 `#1a73e8`），安全帽图标 + 标题。
- 副标题说明用途，并明确「仅供查询」，避免用户寻找编辑入口。

### 3.2 搜索区
- **搜索框**：占位文案「搜索工程名称/地址/施工单位/联系人」，输入即筛（无需点查询）；匹配范围与 PC 端一致（工程名称、所属街镇、工程地址、施工单位、组织撤离单位、联系人、安置场所名称/地址、职务、填报单位、填报人、填报日期）。
- **筛选按钮**：点击底部弹出筛选抽屉；存在生效条件时按钮高亮并显示红点。

### 3.3 筛选条件 Chips
- 生效条件以 chip 展示：「级别：区级 ×」「街镇：南桥镇 ×」「预案：无 ×」「日期：… ~ … ×」，点 × 单独移除。

### 3.4 工地卡片（信息分层）
每张卡片自上而下分四层：

| 层级 | 内容 | 设计说明 |
|------|------|----------|
| ① 标题行 | **工程项目名称**（15px 加粗，可两行）+ 右侧预案徽标 | 「有预案」绿色 / 「无预案」红色——应急场景下无预案工地是重点关注对象，必须一眼可见 |
| ② 标签行 | 项目级别（市级橙/区级蓝/镇级绿）+ 项目类别（青）+ 所属街镇（灰） | 沿用 PC 端标签配色体系 |
| ③ 地址行 | 工程地址（12px 灰，带定位图标） | |
| ④ 数字行 | **总人数** \| **需转移安置人数**（大字号两等分，需转移人数橙色强调） | 人员转移规模是防汛调度核心决策数据，做卡片视觉重心 |
| ⑤ 联系人行 | 联系人 · 职务 + 绿色「拨打」按钮 | 直拨联系人（`tel:`），阻止冒泡不进详情，比进详情再拨少一步 |

- 卡片中不展示组织撤离单位、安置场所、填报信息（中低频字段，收入详情页）。
- 点卡片其他区域进入详情页。

### 3.5 空状态与计数
- 列表顶部显示「共 N 处在建工地」。
- 无数据时显示空状态「暂无符合条件的在建工地」。

## 四、详情页详细设计

### 4.1 头部卡片（蓝色渐变）
- 工程项目名称（18px 加粗）+ 级别/类别/街镇胶囊标签。
- 内嵌数字条：总人数、需转移安置人数（白字大字号），与列表卡片呼应。

### 4.2 快捷操作区（三宫格）
| 操作 | 行为 |
|------|------|
| 拨打联系人 | 调起系统拨号，呼出联系方式 |
| 复制工地地址 | 复制到剪贴板，Toast 提示「工地地址已复制」 |
| 复制安置点地址 | 复制到剪贴板，Toast 提示「安置点地址已复制」；无安置点地址时置灰不可点 |

### 4.3 项目基础信息卡片
| 字段 | 展示规则 |
|------|----------|
| 工程项目名称 | 纯文本 |
| 所属街镇 | 纯文本 |
| 工程地址 | 纯文本 |
| 施工单位名称 | 纯文本 |
| 项目级别 | 彩色标签（市级橙/区级蓝/镇级绿），空值「—」 |
| 项目类别 | 青色标签，空值「—」 |
| 有无应急预案 | 「有」绿色标签 /「无」红色标签，空值「—」 |
| 经度 / 纬度 | 纯文本，空值「—」 |

### 4.4 撤离安置信息卡片
| 字段 | 展示规则 |
|------|----------|
| 组织撤离单位名称 | 纯文本 |
| 总人数 | 纯文本 |
| 需转移安置人数 | 纯文本 |
| 联系人 | 纯文本 |
| 职务 | 纯文本，空值「—」 |
| 联系方式 | 蓝色可点，点击即拨打；空值「—」 |

### 4.5 安置场所信息卡片
| 字段 | 展示规则 |
|------|----------|
| 安置场所名称 | 纯文本，空值「—」 |
| 安置场所地址 | 纯文本，空值「—」 |

### 4.6 填报信息卡片
填报单位、填报人、填报日期（YYYY-MM-DD），空值均显示「—」。

### 4.7 页面切换
- 列表 → 详情：右滑入动画；详情 → 列表：左上角返回按钮。
- **无任何编辑类入口**（无新增、编辑、删除、地图选点按钮）。

## 五、筛选抽屉详细设计

| 区块 | 控件 | 说明 |
|------|------|------|
| 项目级别 | 单选选项组 | 「全部」+ 由数据动态去重生成（市级/区级/镇级） |
| 所属街镇 | 单选选项组 | 「全部」+ 由数据动态去重生成（奉贤区13个街镇/旅游区） |
| 应急预案 | 单选选项组 | 「全部」/「有」/「无」 |
| 填报日期 | 两个日期选择器 | 开始日期 ~ 结束日期，闭区间过滤 |
| 底部操作 | 重置 / 确定 | 重置清空全部条件并立即刷新；确定应用并收起 |

- 点击遮罩可收起抽屉（不应用未确认的改动）。

## 六、筛选与搜索逻辑（与 PC 端一致）

1. 关键字：对工程名称、所属街镇、工程地址、施工单位、组织撤离单位、联系人、安置场所名称/地址、职务、填报单位、填报人、填报日期做合并模糊匹配，不区分大小写，输入即生效。
2. 项目级别 / 所属街镇 / 应急预案：精确匹配。
3. 填报日期：`开始日期 ≤ 填报日期 ≤ 结束日期`，仅填一端时按单端边界过滤。
4. 全部条件为「且」关系叠加生效。

## 七、适配与交互细节

- 页面宽度自适应，最大 420px 居中（兼顾手机与平板竖屏）。
- 适配安全区（顶部刘海、底部 Home 条）。
- 可点区域触控目标 ≥ 40px；卡片点击有缩放反馈。
- 长工程名称允许两行展示，不截断；地址、单位名称自动换行。
- 字段为空时统一显示「—」。
